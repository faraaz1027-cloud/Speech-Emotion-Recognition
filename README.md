# Bangla Speech Emotion Recognition — CSE424

Collaborative research coursework exploring Bangla speech emotion recognition using acoustic feature extraction, clustering, and supervised classification.

## Methods

- Preprocessing and acoustic feature extraction (including MFCCs)
- K-Means and agglomerative clustering
- Supervised model comparisons and evaluation
